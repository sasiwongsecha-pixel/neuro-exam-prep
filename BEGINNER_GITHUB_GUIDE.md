# PART 1: CREATE YOUR GITHUB ACCOUNT

## Step 1.1: Go to GitHub

Open your browser and go to: **https://github.com**

You'll see a page that looks like this:

```
┌─────────────────────────────────────────────┐
│         GitHub Homepage                      │
│                                              │
│    Sign up for GitHub                        │
│    Email: [_____________________]            │
│    Password: [_____________________]         │
│    Username: [_____________________]         │
│                                              │
│    [Sign up for GitHub] button               │
└─────────────────────────────────────────────┘
```

## Step 1.2: Create Your Account

1. Click the **"Sign up for GitHub"** button (top right, or middle of page)
2. Enter your **email address** (e.g., your Gmail or work email)
3. Create a **password** (remember it!)
4. Choose a **username** (e.g., `neurolearner2025`)
   - This will be in your website URL, so keep it simple
5. Click **"Create account"**

## Step 1.3: Verify Your Email

1. GitHub will send you an email
2. Open that email and click the **verification link**
3. Done! Your account is created

# TROUBLESHOOTING

## Q: I uploaded the file but the website shows a 404 error

**Answer:** 
1. Wait 2 minutes (GitHub needs time to publish)
2. Hard refresh your browser: Press **Ctrl + Shift + R** (Windows) or **Cmd + Shift + R** (Mac)

## Q: The hamburger menu doesn't work on my phone

**Answer:**
1. Hard refresh: **Ctrl + Shift + R** 
2. Clear your browser cache
3. Try a different browser (Safari or Chrome)

## Q: How do I update the content?

**Answer:**
1. Go to your GitHub repository
2. Click on `neuro_exam_prep_responsive.html`
3. Click the **pencil icon** (Edit)
4. Make changes
5. Click **"Commit changes"**
6. Changes go live in 30 seconds!

## Q: Can other people edit my file?

**Answer:** No! Only you can edit. Others can only view and use the app.
